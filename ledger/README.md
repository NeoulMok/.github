# 너울목 공개 해시 원장

전향 예보의 사전등록 문서와 회차 매니페스트의 SHA-256을 시각 순서대로 남깁니다. 내용은 싣지 않고 해시만 싣습니다.

- 확인 방법: 원본 파일의 SHA-256이 아래 값과 같은지, OpenTimestamps 증명(`.ots`)이 그 해시를 비트코인 블록에 고정했는지 봅니다(https://opentimestamps.org).
- 회차의 직전 해시는 바로 앞 기록의 SHA-256입니다. 첫 회차의 직전 해시는 사전등록 v1의 해시입니다.
